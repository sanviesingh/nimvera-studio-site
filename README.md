# Nimvera Studio website

This is the separate public-facing website for Nimvera Studio. It links to the Meridian Advisory concept demo.

## Publish with GitHub + Netlify
1. Create a new GitHub repository named `nimvera-studio-site`.
2. Upload `index.html` to the repository root and commit.
3. In Netlify, choose Add new project / Import from Git, connect GitHub, and select `nimvera-studio-site`.
4. Deploy branch `main`. Leave build command blank and use `.` as publish directory if requested.
5. Set project visibility to Public if it is private.
6. Test the website and enquiry form. Netlify Forms submissions should appear in the project's Forms area after deployment.
